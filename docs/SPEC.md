# SPEC.md - สเปกฟีเจอร์ rod-mai-rod (ฉบับละเอียด)

เว็บ/แอปวางแผนการท่องเที่ยว นำ AI มาใช้ร่วมกับ API สภาพอากาศ เพื่อช่วยผู้ใช้ตัดสินใจเรื่องความปลอดภัยของทริป
4 หน้าหลัก + login - สเปกนี้ละเอียดกว่าฉบับร่างแรก ให้ยึดตามนี้เป็นฉบับล่าสุด

## หน้า 1 - Overview

รวมช็อตคัตไปยังฟีเจอร์ต่างๆ ของเว็บ

- **มีทริปที่กำลังจะมาถึง**: แสดงแผนที่ของทริปนั้น พร้อมเส้นทาง + รายละเอียดหมุดหมายต่างๆ ที่กำหนดไว้
- **ไม่มีทริป**: แสดงแผนที่เฉยๆ พร้อมรายงานสภาพอากาศบริเวณใกล้เคียงแบบ **area** (ภาพรวมเป็นพื้นที่ ไม่ใช่รายจุด)

## หน้า 2 - My Trip (หน้าหลักของระบบ)

โครงหน้าแบ่งเป็น 2 ส่วนหลัก: **ทริปที่วางแผนไว้** + **แผนที่**

**ไม่มีทริป**: แสดงแค่แผนที่ + สภาพอากาศบริเวณใกล้เคียงแบบ area (เหมือน Overview)

**กด "สร้างทริป"** - ฟอร์มที่ต้องกรอก:
- ต้นทาง (บังคับ) - เลือกได้ 2 แบบ: กดใช้ตำแหน่งปัจจุบัน หรือเลือกเอง
- ปลายทาง (บังคับ)
- เวลาเริ่มเดินทาง (บังคับ)
- หมุดระหว่างทาง (ไม่บังคับ) - สำหรับจุดแวะพัก เช่น ปั๊มน้ำมัน คาเฟ่ ร้านอาหาร

**กด "Plan"** - เมื่อประมวลผลเสร็จ:

1. **หน้าต่างสรุปสั้น (popup)** ขึ้นมาบอก:
   - ทริปนี้จะใช้เวลาประมาณเท่าไหร่ ถ้าเริ่มเดินทางตามเวลาที่ตั้งไว้
   - **ค่าความเสี่ยง** (risk score) ของอุบัติเหตุจากภัยธรรมชาติ/ฝนตก/อื่นๆ ที่อาจเกิดระหว่างทาง
2. เส้นทางถูกวาดทับลงบนแผนที่กลางหน้าเว็บ
3. **ถ้าประมวลผลได้มากกว่า 1 เส้นทาง หรือเส้นทางแรกที่หาได้มีความเสี่ยงสูง** → ระบบต้องหาเส้นทางที่ปลอดภัยกว่าหรือเร็วกว่ามาแนะนำเพิ่ม (แบบเดียวกับ Google Maps ตอนมีทางลัดที่ไวกว่า)
4. **แท็บด้านขวา** แสดงจุดหมาย/หมุดทั้งหมดที่วางแผนไว้ บอกสภาพอากาศของแต่ละหมุด ณ วันที่จะไปถึง (ฝนตก/ลมแรงหรือไม่)

## หน้า 3 - Safety Map

แสดงแผนที่พร้อมหมุดบอกจุดที่กำลังเกิดฝนตก/ภัยธรรมชาติ

- กดที่หมุด → แสดงรายละเอียดคร่าวๆ (ที่ไหน เกิดเหตุอะไร)
- ใช้ไอคอนสื่อความหมายชัดเจนแยกประเภท: ฝนตก / น้ำท่วม / ดินถล่ม (และประเภทอื่นที่เพิ่มได้ภายหลัง)

## หน้า 4 - Assistant (AI Chatbot)

แชทบอทสำหรับ:

- ถาม-ตอบเรื่องท่องเที่ยวทั่วไป เช่น "เชียงใหม่น่าเที่ยวไหม", "แนะนำที่เที่ยวได้ไหม", "ช่วงนี้เที่ยวที่ไหนดี"
- **สั่งสร้าง/แก้ไขทริปผ่านแชทได้โดยตรง** เช่น "วันนี้อากาศไม่ดี เลื่อนทริป 01 ไปวันถัดไปสิ", "เลื่อนเวลาเป็นช่วงบ่าย" - แชทต้องแก้ไขข้อมูลทริปจริงแล้วสะท้อนกลับไปที่หน้า My Trip ได้ (ไม่ใช่แค่ตอบข้อความเฉยๆ)

## สิ่งที่ต้องคงจากแผนเดิม (ยังใช้ได้เหมือนเดิม)

- ขอบเขต v1: ประเทศไทยเท่านั้น
- Local Risk Model แบบ rule-based (ฝน/ลม/แจ้งเตือนภัยพิบัติ) - ดู threshold ใน `docs/CONTRACT.md`
- Auth: email+password custom, JWT
- Auth เพิ่มเติม: เข้าสู่ระบบด้วย Google (ทำเพิ่ม 4 ต.ค.)
- Font: เดิมวางไว้เป็น Prompt ตอนนี้ใช้ **Noto Sans Thai** ทั้งเว็บ (เก็บไฟล์ใน repo)
- API ที่ใช้จริง: OSRM (เส้นทาง), Esri (แผนที่), Open-Meteo, GDACS, USGS, GISTDA (น้ำท่วมจากดาวเทียม), HDMS กรมทางหลวง (ถนนปิด), Photon + Overpass (สถานที่) · Longdo, Thaiwater/HII, TMD ที่วางแผนไว้ยังไม่ได้ต่อ รายละเอียดใน README หัวข้อ 3
