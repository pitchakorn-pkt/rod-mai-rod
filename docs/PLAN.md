# PLAN.md - คิวงานของแต่ละโมดูล

> บันทึกการแบ่งงานช่วงพัฒนา (ก.ย. 2569) เก็บไว้เป็นประวัติ สถานะล่าสุดของระบบ ไฟล์จริงของแต่ละหน้า และวิธีรัน ดู [`README.md`](../README.md)

**ไม่มีกำหนดวัน** ทำงานในคิวของตัวเองตามลำดับ งานไหนผ่านรีวิวและ merge เข้า `dev` แล้ว หยิบงานถัดไปได้ทันที ไม่ต้องรอใคร
งานที่ต้องรอของคนอื่น มีเขียนไว้ในช่อง "รอ" พอของที่รอเข้า `dev` แล้ว เจ้าของโปรเจกต์จะแจ้งในห้องโมดูลของคนที่รอ
ระหว่างรอ ทำงานข้อถัดไปที่ไม่ต้องรอไปก่อนได้เลย ทุกโมดูลมี stub ให้ต่ออยู่แล้ว

ยิ่งเสร็จเร็ว ยิ่งมีเวลาเหลือไว้ทดสอบรวม แก้บั๊ก และเก็บรายละเอียด

## วิธีทำงาน

1. หยิบงานข้อแรกที่ยังไม่เสร็จในคิวของตัวเอง (รายละเอียดอยู่ในไฟล์งานที่ปักหมุดในห้องโมดูล)
2. PR เล็ก หนึ่งงานต่อหนึ่ง PR เปิดเข้า `dev`
3. ผลรีวิวเด้งเข้าห้องโมดูลของตัวเอง ผ่าน = merge ได้เลย ไม่ผ่าน = แก้ตามไฟล์ผลรีวิวแล้ว push เพิ่มใน branch เดิม
4. merge แล้วบอกในห้องโมดูล แล้วหยิบงานถัดไป
5. ติดเกิน 1 ชั่วโมง ทักใน #help ทันที

`dev` เข้า `main` เมื่อไหร่ก็ได้ที่ `dev` ผ่าน smoke และเส้นสาธิตบนเว็บจริง ไม่ต้องรอให้ครบทุกโมดูล
